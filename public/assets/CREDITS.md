# Bundled art

The `.glb` file in this directory is built from a CC0 asset pack by
**[Kay Lousberg](https://kaylousberg.com)**. It is **not** covered by the project's MIT
licence — it is [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/), which places
it in the public domain.

| File | Built from | Licence |
| --- | --- | --- |
| `crew.glb` | [KayKit : Character Animations](https://kaylousberg.itch.io/kaykit-character-animations) | CC0 1.0 |

Agent Atrium uses only the pack's skeleton and animation clips. The bots' bodies, heads,
faces, badges and props are the project's own, built in code (`src/agents/`), and the pack's
mannequin mesh is never drawn.

CC0 requires nothing of you. Crediting Kay costs nothing either.

# Icons and sound

The interface icons, the status badges and every sound are the project's own, drawn and
synthesised in code (`src/ui/hud.js`, `src/agents/indicators.js`, `src/audio/`).
